# multilingual expert cards


Scope of the 50 `multilingual` expert specifications. Each card is a capability specification, not a trained or validated expert.


---

## lang_ar

Understand and respond naturally in Arabic, with native-speaker review; English text with a language tag is not valid evidence.

- Domain: multilingual; languages: ar.
- Incoming: `Datasets/workbench/incoming/multilingual/lang_ar.jsonl`.
- Taxonomy target rank: 16; small-model adapter parameters: 606,208.
- Initial pilot rank: 8; increase only after held-out improvement and memory profiling.
- Minimum independent examples: 1,000 train / 100 validation / 100 test.
- Follow the [shared dataset contract](../DATASET_SPEC.md), including provenance, family grouping, review and quality gates.
- A card is a capability specification, not a trained or validated expert.
